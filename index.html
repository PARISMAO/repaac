REPAAC — Administration
✅ Code des comptes copié !
Étapes pour activer sur tous les appareils :
1. Allez sur github.com/PARISMAO/repaac → Settings → Secrets and variables → Actions
2. Créez ou mettez à jour le secret : REPAAC_USERS
3. Collez le code copié comme valeur du secret
4. Allez dans Actions → Re-run all jobs
5. Dans 30 secondes, tous les appareils auront accès aux comptes !
